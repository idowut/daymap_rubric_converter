# DayMap Rubric Converter

My partner is an educator who uses DayMap to manage their classes, and they were frustrated that DayMap rubrics could not be exported out of DayMap as an easy file to interact with. So I wrote a small tool to convert DayMap rubrics into a format that can be opened by Excel or similar.

This is originally forked from <a href="https://github.com/amdgeo/turnitin_rubric_converter/releases/tag/v2023.0">here</a>. It's been slightly modified to work with DayMap rubrics instead of Turnitin rubrics.

All credits to @amdgeo for the original code.
